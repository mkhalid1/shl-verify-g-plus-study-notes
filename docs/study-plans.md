# Study plans

Two plans: one for a week, one for when the invitation has already arrived. Both start with the [15-minute diagnostic](diagnostic.md) so you know which ability to work on first. Expect 45 to 90 minutes a day on the 7-day plan.

## 7-day plan

| Day | Focus | What to do |
|---|---|---|
| 1 | Baseline | Read the [test overview](test-overview.md) and check [which version you have](versions.md). Take the [diagnostic](diagnostic.md). Note your weakest ability. |
| 2 | Numerical | Read the [numerical guide](sections/numerical-reasoning.md). Do all 5 items with a calculator. For each miss, write which operation you used and which you should have used. |
| 3 | Deductive | Read the [deductive guide](sections/deductive-reasoning.md). Learn the common forms table until you can write it from memory. Do all 5 items. |
| 4 | Inductive | Read the [inductive guide](sections/inductive-reasoning.md). Do all 5 items, listing features for each before answering. |
| 5 | First timed run | Take a full timed practice test, such as the [free one on PrepClubs](https://prepclubs.com/free-practice-tests/shl-general-ability?utm_source=github&utm_medium=referral&utm_campaign=6cqf97&utm_content=shl-verify-g-plus). Score it by ability. Read the [timing guide](timing.md). |
| 6 | Fix the weakest ability | Go back to its traps list. Redo its items without the answers. Then try SHL's own practice test for that ability. |
| 7 | Second timed run and rest | One more timed run in the morning. Compare with day 5. Read the [test-day checklist](test-day-checklist.md). Stop by early evening. |

### How to review a missed item

The review is where the improvement comes from. For each miss, answer three questions:

1. **What did I do?** For example: divided by the new value, reversed a rule, missed the colour change.
2. **What on the screen should have stopped me?** Name the word, unit or frame.
3. **What will I check next time?** One short habit, such as "base value first" or "list every feature".

Keep these in one list. By day 6 the same two or three mistakes will be repeating. Fixing those is worth more than any number of new questions.

## 2-day plan

For when the link has arrived and the deadline is close.

| When | What to do |
|---|---|
| Day 1, morning | Take the [diagnostic](diagnostic.md). Read the method and traps for your weakest ability only. |
| Day 1, afternoon | Do that ability's 5 practice items. Review every miss using the three questions above. |
| Day 1, evening | Read the other two methods and the [deductive common forms](sections/deductive-reasoning.md#common-forms-to-know). Skip their items if you are short of time. |
| Day 2, morning | One full timed run. Note where you ran over time. |
| Day 2, afternoon | Read the [timing guide](timing.md) and the [checklist](test-day-checklist.md). Take the real test when you are fresh, ideally not late at night. |

## What not to do

- **Do not try to memorise questions.** The test is adaptive and draws different questions for different people.
- **Do not do ten practice tests without reviewing them.** One reviewed test beats five unreviewed ones.
- **Do not skip the easy-looking ability.** Inductive is where you save time for numerical, so make it fast and sure.
- **Do not take the real test tired.** You can usually choose when to start within the deadline. Use that.
