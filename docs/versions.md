# Which SHL general ability test do you have?

Many invitations just say "SHL general ability assessment" or "SHL online test". The product behind that wording can vary, and the screens look quite different between versions. This page helps you work out which one you are facing so you practise the right format.

## The versions you may hear about

| Name | Format | What we know from SHL |
|---|---|---|
| **Verify G+** | Multiple choice, adaptive | Up to 30 questions (10 numerical, 10 deductive, 10 inductive), 36 minutes, one sitting. This repo is built around it. |
| **Verify Interactive G+** | Interactive: a drag and drop format rather than ticking one option | SHL's practice site offers a "General Ability Test (Mobile-Enabled, Interactive)" that uses a drag and drop format. SHL's sample Interactive G+ report scores the same three abilities. |
| **Single-ability Verify tests** | Numerical, deductive or inductive on their own | SHL lists separate numerical, deductive and inductive practice tests, in both interactive and standard multiple-choice formats. |

Sources: [Verify G+ fact sheet](https://www.shl.com/assets/documents/rebranded-assets/product-factsheet-verify-g-plus.pdf), [SHL practice tests](https://www.shl.com/shldirect/en/practice-tests/), [sample Verify Interactive G+ report](https://service.shl.com/docs/Verify%20Interactive%20G%20Plus%20Ability%20Report%20UKE.pdf). SHL does not publish question counts or timings for the interactive version on these pages, so we do not give any.

## How to tell which one you have

1. **Read the invitation and the instructions screen.** The instructions before the first question usually state the number of questions and the time limit. That is the most reliable source you will get.
2. **Ask the employer or recruiter** if the invitation is unclear. It is a normal question and they will usually tell you the test name.
3. **Try both SHL practice formats.** SHL's own practice site has interactive and multiple-choice versions. If one looks like what your instructions describe, you have your answer.

## What stays the same across versions

- The three abilities: numerical, deductive and inductive reasoning.
- The core methods in this repo: read the question first, write down key facts, test every option, and check every feature of a pattern.
- The scoring idea: your result is compared with a group of other test takers, not marked against a fixed pass line.

## What changes

- **Answer mechanics.** SHL describes the interactive format as drag and drop. Read each instruction carefully before you answer.
- **Pace feel.** Interactive tasks can take longer to answer even when the reasoning is the same. Do at least one timed run in the format you will actually face.

## Practise the format you will face

For the multiple-choice style, the [free SHL Verify G+ practice test on PrepClubs](https://prepclubs.com/free-practice-tests/shl-general-ability?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=shl-verify-g-plus) mirrors the three question types. For the interactive style, use [SHL's own practice tests](https://www.shl.com/shldirect/en/practice-tests/).
